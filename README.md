# Sentissi Legal Advisory — Site Web

Site web professionnel du cabinet **Sentissi Legal Advisory** (SLA), basé à Casablanca.

## Structure

```
sentissi-legal/
├── index.html          # Page d'accueil
├── services.html       # Nos 7 Pôles juridiques
├── equipe.html         # Mohammed Sentissi & Soufiane Elahmadi
├── formation.html      # Programmes de formation
├── contact.html        # Formulaire de contact
├── css/
│   └── sentissi.css    # Styles personnalisés SLA
├── vendor/
│   ├── css/            # Bootstrap 5, Swiper, Crafto styles
│   └── js/             # jQuery, vendors, Crafto main.js
└── .gitignore
```

## Technologies

- HTML5 / CSS3
- Bootstrap 5 (inclus dans `vendor/`)
- Swiper.js (slider hero)
- Font Awesome 6.5.1 (CDN)
- Google Fonts : Playfair Display + DM Sans
- Crafto template (structure et animations)

## Déploiement GitHub Pages

1. Pousser le dépôt sur GitHub
2. Aller dans **Settings → Pages**
3. Source : `Deploy from a branch` → `main` → `/ (root)`
4. Le site sera disponible à `https://<username>.github.io/<repo>/`
